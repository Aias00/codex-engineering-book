# 第 4 章　读懂 Rust 所需的最少知识

你不需要先学完整门语言才能阅读工程。先认出函数的输入、返回值和错误路径，就能理解许多局部行为。本章使用当前仓库的一段短函数练习这个方法。

## 先读签名，再读函数体

`codex-rs/utils/string/src/lib.rs` 定义了这个函数：

```rust
pub fn take_bytes_at_char_boundary(s: &str, maxb: usize) -> &str {
    if s.len() <= maxb {
        return s;
    }
    let mut last_ok = 0;
    for (i, ch) in s.char_indices() {
        let nb = i + ch.len_utf8();
        if nb > maxb {
            break;
        }
        last_ok = nb;
    }
    &s[..last_ok]
}
```

暂时忽略 `#[inline]` 这样的属性。签名里的 `pub` 表示可以公开使用，`fn` 表示函数，`s` 和 `maxb` 是输入名称。`&str` 是对 UTF-8 文本切片的借用，可以先理解成“查看已有字符串的一段”；`usize` 是适合表示长度和索引的无符号整数。箭头后的 `&str` 表示返回的也是文本切片。

函数名大致可以读成：“在字符边界上，取不超过指定字节数的前缀。”这个解释比逐字翻译每个关键字更有价值，因为它告诉你应该怎样验证行为。

## 用“你好”验证一遍

在 UTF-8 中，常见汉字“你”和“好”各占 3 个字节，因此“你好”共有 6 个字节。字节预算是 4 时，不能截取前 4 个字节后直接当作有效字符串：第 4 个字节已经进入“好”的编码，但没有取完整。

上面的函数先看整个字符串是否放得下。放不下时，`char_indices()` 枚举字符的起始字节位置，`len_utf8()` 给出该字符占几个字节。只有完整字符的结尾不超过预算，才更新 `last_ok`。

| 输入与预算 | 合法返回值 | 原因 |
|---|---|---|
| `"你好"`，0 | 空字符串 | 没有空间容纳完整字符 |
| `"你好"`，2 | 空字符串 | “你”需要 3 字节 |
| `"你好"`，3 或 4 | `"你"` | 第一个字完整，第二个放不下 |
| `"你好"`，6 | `"你好"` | 全部内容放得下 |

Rust 里的 `char` 也不一定等于人眼看到的完整文字单元。组合字符和某些 emoji 可能由多个 Unicode 标量值组成。这里保证的是合法 UTF-8 边界，不是完整保留所有视觉字形。把保证说准确，才知道测试应该覆盖到哪里。

## 变量、循环和返回值

`let mut last_ok = 0` 表示建立一个可以更新的变量；没有 `mut` 的绑定默认不允许重新赋值。`for` 遍历每个字符，`break` 在预算不足时结束循环。

函数末尾的 `&s[..last_ok]` 没有分号。Rust 可以把块中最后一个表达式作为返回值。中间的 `return s;` 则是提前返回。遇到一个长函数，先标出所有返回位置，往往就能理解不同条件下的结果。

这里的输出借用输入文本，没有重新创建一份相同内容。你暂时可以把所有权和借用看作一套规则：谁负责数据的生命期，谁只是暂时查看或修改它。更复杂的生命期标注可以以后学，不妨碍理解这个函数的用途。

## 再认四个常见形状

`struct` 通常把相关字段放在一起，比如一份配置；`enum` 表示几种可能状态之一，比如某条消息可能是开始、增量或完成；`match` 逐种处理这些可能；`Option<T>` 表示某个值可能存在，也可能不存在。

`Result<T, E>` 表示操作可能成功，也可能返回错误。源码里的 `?` 常用来提早返回错误，而不是忽略它。不要简单把它读成“自动解决错误”；实际含义更接近“失败就把错误交给上层”。

`async fn` 定义可以异步执行的函数，`.await` 表示等待某个异步结果。等待网络或子进程时，程序有机会处理别的任务。不过异步不自动等于并行，也不代表错误会消失。

`use` 把别处定义的名称引入当前作用域，`mod` 声明模块。阅读时遇到不认识的类型，可以先跳到定义，看看它的数据形状，再回到调用处。

## 依赖和测试要一起看

如果一个短函数只用标准库，比较适合单独练习；如果它依赖大量异步服务，就适合先读现成测试。测试可以帮助你观察作者认为重要的边界，例如空字符串、错误输入、取消和超时。

不过测试名字不是全部证据。要读断言：输入究竟是什么，比较了哪个字段，是否真的经过目标分支？一个测试通过，只能支持它覆盖到的行为。

## 小练习与参考答案

问题：对 `"A你B"` 设置 4 字节预算，应该返回什么？

参考答案：`"A你"`。ASCII 字母 A 占 1 字节，“你”占 3 字节，总共 4。B 再占 1 字节，无法容纳。

问题：如果返回值要始终拥有独立的一份字符串数据，当前返回类型还能直接满足要求吗？

参考答案：当前返回的是借用切片，不会为结果独立分配所有内容。要返回拥有数据的字符串，通常会考虑 `String`，同时要重新评估接口和分配成本。本书不要求你修改这个真实接口。
