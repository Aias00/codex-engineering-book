# 附录 A　遇到名词时翻这里

下面的解释以本书语境为主。你可以把术语当作路标，不必先背完再读正文。

| 名词 | 在本书中怎么理解 |
|---|---|
| CLI | 命令行界面，通过命令和参数操作程序 |
| TUI | 在终端里显示的交互界面，支持持续输入和进展展示 |
| Shell | 解释命令的程序，例如 zsh、bash、PowerShell |
| 工作目录 / cwd | 当前操作解析相对路径的基准位置 |
| 进程 | 正在运行的程序实例，可能再启动子进程 |
| 标准输入 / stdin | 给进程发送文字或其他数据的通道 |
| 标准输出 / stdout | 进程输出结果的通道；协议模式下可能承载结构化消息 |
| 标准错误 / stderr | 常用于诊断的独立通道，不能仅凭是否有文字判断成功 |
| 退出状态 | 进程结束时返回的数字；通常 0 表示成功 |
| 仓库 / repository | 包含源码与历史记录的工程集合 |
| 工作区 / worktree | 你正在查看和编辑的那份文件树 |
| 提交 / commit | 有唯一编号的一次 Git 历史快照 |
| 差异 / diff | 文件版本之间的变化，需注意默认不展示未跟踪文件 |
| crate | Rust 的编译单元，可以提供库或可执行程序 |
| Cargo | Rust 的依赖管理、构建与测试工具 |
| workspace | 在一个配置下组织多个 Rust 包的工作空间 |
| just | 执行仓库定义的命令配方，配方可以调用 Cargo 等其他工具 |
| Bazel | 支持跨语言、跨目标构建的工具；本仓库另一套构建入口 |
| 锁文件 | 记录依赖解析结果，帮助重复构建 |
| 模型提供者 | 定义请求发往哪个模型服务以及连接方式的配置与实现 |
| 上下文 | 模型当前请求可用的信息，不等同于磁盘上的全部文件 |
| thread | 可持续追加多轮输入的会话容器 |
| turn | 一轮用户输入驱动的工作过程，内部可以有多次模型请求 |
| 流式响应 | 结果分批到达，程序可以边收边显示或处理 |
| token | 模型处理文本的计量单元，不等于固定数量的汉字或字节 |
| 工具调用 | 模型提出的结构化动作请求，需要程序实际调度执行 |
| runtime | 本文工具语境下负责把动作落到执行环境的一层；不要把它与所有同名运行时混淆 |
| app-server | 提供会话、回合、事件等服务接口的组件，并不只指远程服务器 |
| 协议 | 两端约定的消息形状、顺序和含义 |
| JSON | 用对象、数组等结构表达数据的文本格式 |
| JSONL | 每行一个 JSON 值，适合逐条处理事件 |
| JSON-RPC | 用 JSON 表达方法请求、响应和通知的一类协议 |
| SSE | 一种服务端向客户端连续发送事件的 HTTP 流式方式 |
| SDK | 对进程、协议和接口的编程语言包装 |
| 认证 / authentication | 证明你是谁、使用什么账户或凭据 |
| 审批 / approval | 决定某个动作是否得到授权的过程 |
| 执行策略 | 对命令等动作匹配规则并得出决策的机制 |
| 沙箱 / sandbox | 在操作系统层落实访问和隔离限制的执行环境 |
| MCP | 连接外部工具、资源等能力的协议；可用工具和权限仍由实际配置决定 |
| skill | 围绕某类工作提供的说明与资源包，常从 SKILL.md 开始 |
| AGENTS.md | 放在工程中的代理工作说明，适用范围和加载规则需要结合实现 |
| snapshot 测试 | 将输出与保存的预期快照比较，更新快照前应核对行为 |
| fixture | 测试使用的固定输入、目录或模拟数据 |
| regression 回归 | 已解决的问题再次出现；回归测试用于捕捉它 |

## 三组最容易混淆的词

**thread 与 turn。** Thread 像一本持续记录的笔记，turn 像你新提出的一项工作。一次 turn 里可以连续搜索、读文件和测试，所以不能把“收到一段模型文字”直接等同于“一轮结束”。

**字节、字符与 token。** UTF-8 用若干字节编码一个 Unicode 标量值；人眼看到的文字单元还可能包含多个标量值；模型 token 又使用另一套切分方式。第 4 章的小函数保证 UTF-8 边界，第 12 章的练习验证这个保证，不声称解决全部视觉排版或模型计量问题。

**认证、审批与沙箱。** 认证解决账户身份，审批解决动作授权，沙箱解决进程实际能访问的资源。三者没有一个可以自动代替另外两个。已经登录并不代表任意命令都应执行；审批通过也不代表平台限制会被全部移除。
